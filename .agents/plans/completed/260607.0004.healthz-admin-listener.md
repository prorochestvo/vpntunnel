# Task Breakdown

## Overview

v4 / Plan 005 adds a single thing the operator-facing world has been missing
since v1: an out-of-band liveness probe. Docker `HEALTHCHECK`, systemd
`WatchdogSec`, an external Uptime Robot — all of them want to ask "is this
proxy still up and is the tunnel actually carrying traffic?" without having to
HTTP-through-the-proxy to find out.

Concretely v4 ships:

1. **A new optional sub-interface** `tunnel.HealthReporter` (mirrors the
   `tunnel.DialerCloser` pattern) with one method:
   `LastHandshake() (time.Time, error)`. The WireGuard dialer implements it
   by parsing `last_handshake_time_sec` out of `device.IpcGet` output.
   Future non-WG dialers can either implement it differently or skip it
   entirely — the /healthz handler type-asserts and degrades gracefully.
2. **A new package `internal/transport/adminserver/`** wrapping a second
   `*http.Server` on a separate bind (default `127.0.0.1:8081`). Mirrors
   `httpserver/` in shape (`New`, `Start`/`StartOn`, `Shutdown`) but with
   a `*http.ServeMux` for explicit routes and **no** hijack support, **no**
   `ReadHeaderTimeout` of `DialTimeout` semantics, **no** CONNECT path. It
   is the boring side of the binary.
3. **A new package `internal/health/`** holding the route handler:
   `NewHandler(reporter, maxAge, opLog) http.Handler`. Returns
   `200 {"status":"ok","handshake_age_seconds":N}` when the tunnel last
   handshaked within `maxAge`; `503 {"status":"unhealthy","reason":<tag>,
   "handshake_age_seconds":N}` otherwise (including never-handshaked).
   Unknown paths and non-GET methods on the admin mux get a plain 404 —
   no `/`, no `/metrics`, no `/readyz` in v4.
4. **Two config blocks**: `admin{listen, shutdown_timeout}` defaulting to
   `127.0.0.1:8081` / `5s`, and `health{handshake_max_age}` defaulting to
   `180s`. Both blocks are optional — missing → defaults — and the
   existing `Load` permissive-decode behavior is unchanged in this plan.
5. **`cmd/httpproxy/main.go` wiring**: a second goroutine launches the admin
   server in parallel with the proxy server; one shared signal context
   triggers both shutdowns; one `errCh` (buffered, size 2) collects fatal
   start failures from either side. WG dialer Close runs *after* both
   shutdowns return.

What v4 explicitly does NOT ship:
- An active dial probe (e.g. periodic `tnet.DialContext("1.1.1.1:443")`).
  Handshake-age-only is the v4 default; see Risks for the trade-off and
  Trade-offs (a) for the alternative that was considered and rejected.
- `/metrics`, `/readyz`, `/debug/pprof`. None.
- Any auth on `/healthz`. The 127.0.0.1 default is the auth.
- Periodic health-state logging. The handler emits at most a `Debug` log
  per request.

Net diff estimate: ~250 lines added (handler, server wrapper, parser
method, config block, wiring, tests), ~0 deleted. Two new packages, one
new method on the WG dialer.

## Assumptions

### Locked decisions (from user spec — do NOT revisit)

- Separate admin listener; **NOT** a route on the proxy listener.
- Default `admin.listen = "127.0.0.1:8081"`, `admin.shutdown_timeout = 5s`.
- Probe strategy = handshake-age-only. No active dial probe in v4.
- `tunnel.HealthReporter` is a NEW optional sub-interface alongside
  `tunnel.DialerCloser` — not a method added to `tunnel.Dialer`.
- `adminserver` is its own package under `internal/transport/`.
- `health.NewHandler` lives in `internal/health/` (justification under
  "Open design decisions resolved" below).
- `/healthz` returns JSON. Body schemas are fixed:
  - 200: `{"status":"ok","handshake_age_seconds":<int>}`
  - 503: `{"status":"unhealthy","reason":"<tag>","handshake_age_seconds":<int>}`
- No `/metrics`, no `/readyz`, no auth on `/healthz`.
- 503 body never leaks `peer_endpoint`, any key material, or fields beyond
  the schema above.
- Handshake age of zero (never handshaked) is **unhealthy** with
  `reason: "no_handshake"`.
- Admin server uses the same `opLog` as the proxy server.
- Startup log line "admin server listening on X" — yes, mirrors the
  existing `httpserver` info log.
- No periodic health-state log emission.
- No `make curl-health` target.

### Open design decisions resolved in this plan

- **Package for `NewHandler`**: `internal/health/` rather than co-located
  in `cmd/httpproxy/`. Why: it consumes `tunnel.HealthReporter` (an
  internal contract) and produces an `http.Handler`; the WG dialer is its
  dependency in v4 but a stubbed reporter is the natural test seam, and
  putting the handler in `cmd/httpproxy/` would force test code to live
  next to `main.go`. The strict consumption rule says single-consumer code
  lives in `cmd/`, but the testing argument outweighs it: the handler is a
  pure function of its inputs and earns a `internal/health/` package
  whose test seam is a fake `HealthReporter`. One file, one test file,
  one consumer in v4; borderline but justified.
- **503 body schema**: include `handshake_age_seconds` even on failure
  (operator's debugger wants the number). Never-handshaked and
  reporter-error return `handshake_age_seconds: -1` (sentinel — JSON
  can't represent +Inf/nil-safely; `-1` reads unambiguously as "no
  value yet").
- **Tag set for `reason`**: `"no_handshake"` (handshake_age zero),
  `"handshake_stale"` (handshake_age > maxAge), `"reporter_error"` (the
  underlying `LastHandshake()` returned a non-nil error). Fixed,
  documented, no free-form strings — operator scripts grep for them.
- **`HealthReporter` as a sub-interface of `tunnel.Dialer`?** No.
  `HealthReporter` does **not** embed `Dialer`. It is standalone — a
  parallel optional contract that a Dialer implementation MAY also
  implement. This matches what we actually want: the `/healthz` handler
  needs only `LastHandshake()`; making it depend on the full Dialer
  surface would couple health checking to dialing for no reason.
  (DialerCloser embeds Dialer because a closer is *also* a dialer; a
  health reporter is *not* a dialer.)
- **`cmd/httpproxy/main.go` passes `*WireGuardDialer` directly to
  `health.NewHandler`**: today the concrete type from `wireguard.NewDialer`
  is `*WireGuardDialer` (not `tunnel.Dialer`), which already implements
  every interface it needs. The call site does NOT need a type assertion
  — the implicit interface satisfaction works. If a future refactor
  returns `tunnel.Dialer` from the constructor, that's the moment to add
  `if hr, ok := dialer.(tunnel.HealthReporter); ok { ... }`. v4 doesn't.

### Cross-plan contract (with Plan 004 — Deploy)

- Plan 004 reserves `127.0.0.1:8081` and `EXPOSE`s it in the Dockerfile.
  Plan 005 OWNS what's bound to that port. Port number is the contract.
- Plan 004 introduces a `-healthcheck` flag mode that TCP-dials the admin
  port (or HTTPs `/healthz` — Plan 004's call). Plan 005 does NOT depend
  on this: the admin listener simply accepts TCP and serves `/healthz`
  per the schema above. Plan 004 can ship without Plan 005 (TCP dial
  succeeds even if nothing serves) and Plan 005 can ship without Plan 004
  (operator probes manually with `curl`).
- Either plan can land first; their only shared symbol is the port
  number, and both pull it from `config.Admin.Listen` (which Plan 005
  owns the definition of). Plan 004's Dockerfile should reference
  `127.0.0.1:8081` as a documented default, not import any Go symbol.

### Required reading (engineer)

- `plans/completed/260607.0002.adopt-wgquick-conf-drop-bootstrap.md` —
  current shipped state; the wiring patterns there (defer order, signal
  context, dialer Close) are what Plan 005 extends.
- `internal/transport/httpserver/server.go` — copy its shape for
  `adminserver`. Specifically the `Start`/`StartOn`/`Shutdown` split.
- `golang.zx2c4.com/wireguard/device` — `Device.IpcGet(io.Writer) error`
  is the API. Output is line-based: `key=value\n`. Per-peer block follows
  `public_key=<hex>` and includes `last_handshake_time_sec=<int>` and
  `last_handshake_time_nsec=<int>`. Both lines are present even when
  there has been no handshake — values are `0`. **Parse defensively**:
  unknown keys are skipped; we read only what we need.

## Tasks

### Task 1: New optional interface `tunnel.HealthReporter`

- **Description:** Extend `internal/tunnel/dialer.go` with a new exported
  interface and a `time.Time`-returning method. **Do not** modify
  `Dialer` or `DialerCloser`. Mirror the `DialerCloser` godoc style and
  update the package godoc framing to mention the new interface in one
  sentence (do not rewrite the whole doc).

  ```go
  // HealthReporter is implemented by Dialers that can report tunnel-level
  // health to an external probe. v4 uses this only for the WireGuard
  // dialer's WireGuard handshake age; future implementations may report
  // different signals (e.g. last successful connect, queue depth).
  //
  // HealthReporter is intentionally NOT a sub-interface of Dialer: the
  // /healthz handler depends only on LastHandshake, not on DialContext,
  // and coupling the two would force fake reporters in tests to satisfy
  // the full Dialer surface. Callers that need both must type-assert
  // separately.
  type HealthReporter interface {
      // LastHandshake returns the most recent moment the tunnel's
      // underlying transport completed a handshake with the peer, in the
      // implementation's local clock (typically time.Now()'s clock).
      //
      // A zero time.Time (IsZero() == true) means no handshake has yet
      // completed since the dialer was constructed; callers MUST treat
      // this as "not yet healthy", NOT as "infinitely fresh".
      //
      // Errors returned by LastHandshake represent a failure to query the
      // underlying transport (UAPI parse failure, device closed). The
      // returned time.Time is unspecified when err != nil.
      LastHandshake() (time.Time, error)
  }
  ```

  Add the `time` import. Update the package godoc to read (one-line
  change): "Callers use Dialer exclusively; implementations that own
  resources also implement DialerCloser; implementations that report
  tunnel health also implement HealthReporter."

- **Acceptance Criteria:**
  - [ ] `internal/tunnel/dialer.go` declares `HealthReporter` with the
        method above and a godoc that documents the zero-time semantics
        explicitly.
  - [ ] `HealthReporter` does NOT embed `Dialer`. (The compile-time
        assertion `var _ HealthReporter = (*wireguard.WireGuardDialer)(nil)`
        in Task 2 is the proof.)
  - [ ] `Dialer` and `DialerCloser` are unchanged.
  - [ ] Package godoc mentions `HealthReporter` in one sentence.
  - [ ] `go vet ./internal/tunnel/...` clean.
- **Pitfalls:**
  - Don't put this in a new sub-package. Keep `tunnel` flat — every
    interface the dialer abstraction needs lives in `dialer.go`.
  - Don't make `LastHandshake` return `time.Duration` ("age"). The probe
    decides what's stale; the reporter reports a *time*. This keeps the
    reporter cheap to test (frozen clock) and the handler honest about
    where the "now" reference comes from.
- **Complexity:** Easy.

### Task 2: Implement `LastHandshake` on `*WireGuardDialer`

- **Description:** Add a method on `*wireguard.WireGuardDialer` that:

  1. Calls `d.dev.IpcGet(&buf)` where `buf` is a `strings.Builder`
     (matches the idiom in `buildIpcSet`).
  2. Scans the result line by line. For each `last_handshake_time_sec=<int>`
     line, parses the integer and tracks the maximum across peers
     (v4 has exactly one peer, but defend against future multi-peer).
     **Ignore `last_handshake_time_nsec`** in v4 — second precision is
     enough for a 180s threshold; the nsec field adds parsing surface
     for zero operational value.
  3. If no `last_handshake_time_sec` line is found OR the maximum value
     parsed is `0`, return `(time.Time{}, nil)`. Note: zero is **not**
     an error — it's the documented "no handshake yet" sentinel from
     `HealthReporter`'s godoc.
  4. Otherwise return `(time.Unix(maxSec, 0), nil)`.
  5. If `IpcGet` itself returns a non-nil error, return
     `(time.Time{}, fmt.Errorf("wireguard: ipcget: %w", err))`.

  Place the method in a new file `internal/tunnel/wireguard/health.go`
  (keeps the dialer file focused on lifecycle). Per the file-declaration-
  order rule, the file has only this one exported method on
  `*WireGuardDialer` plus its private parsing helper; structure is:

  ```go
  package wireguard

  import (
      "bufio"
      "fmt"
      "strconv"
      "strings"
      "time"
  )

  // LastHandshake reports the most recent moment the WireGuard device
  // completed a handshake with the peer, by parsing IpcGet output. A
  // zero time.Time means no handshake has yet completed since
  // NewDialer returned. See tunnel.HealthReporter for the contract.
  //
  // LastHandshake is safe for concurrent use: IpcGet acquires the
  // device's internal lock. It is O(peers) and allocates one
  // strings.Builder per call; cheap enough for a /healthz handler
  // even under sustained polling.
  func (d *WireGuardDialer) LastHandshake() (time.Time, error) {
      var b strings.Builder
      if err := d.dev.IpcGet(&b); err != nil {
          return time.Time{}, fmt.Errorf("wireguard: ipcget: %w", err)
      }
      return parseLastHandshake(b.String())
  }

  // parseLastHandshake extracts the latest last_handshake_time_sec
  // value across all peers in a UAPI Get response. Returns zero
  // time.Time if no handshake has occurred yet (every peer reports 0)
  // or if no peer block was found.
  func parseLastHandshake(uapi string) (time.Time, error) {
      var maxSec int64
      sc := bufio.NewScanner(strings.NewReader(uapi))
      for sc.Scan() {
          line := sc.Text()
          const prefix = "last_handshake_time_sec="
          if !strings.HasPrefix(line, prefix) {
              continue
          }
          n, err := strconv.ParseInt(line[len(prefix):], 10, 64)
          if err != nil {
              return time.Time{}, fmt.Errorf("parse %q: %w", line, err)
          }
          if n > maxSec {
              maxSec = n
          }
      }
      if err := sc.Err(); err != nil {
          return time.Time{}, fmt.Errorf("scan uapi: %w", err)
      }
      if maxSec == 0 {
          return time.Time{}, nil
      }
      return time.Unix(maxSec, 0), nil
  }
  ```

  Add a compile-time interface assertion in `dialer.go` next to the
  existing two:

  ```go
  var _ tunnel.HealthReporter = (*WireGuardDialer)(nil)
  ```

  Tests in a new `health_test.go` (separate file because the existing
  `dialer_test.go` is already large and focused on construction/dial
  semantics). One top-level `TestWireGuardDialer_LastHandshake` and one
  top-level `TestParseLastHandshake`, every scenario as a `t.Run`:

  - `TestWireGuardDialer_LastHandshake`:
    - "returns zero time on freshly-constructed device" (live device,
      no peer ever handshakes — `minimalOpts` from `dialer_test.go`).
    - "propagates IpcGet failure as error" — Close the device, then
      call `LastHandshake`; expect non-nil error containing `"ipcget"`.
  - `TestParseLastHandshake`:
    - "returns zero time on empty input"
    - "returns zero time when last_handshake_time_sec=0"
    - "returns time.Unix(N,0) when last_handshake_time_sec=N"
    - "returns max across multiple peers"
    - "ignores unknown keys" (`private_key=...`, `public_key=...`,
      `endpoint=...`, `allowed_ip=...`)
    - "returns error on non-integer value"
    - "ignores last_handshake_time_nsec (does not influence result)"

  `parseLastHandshake` is unexported but **must** be tested directly —
  it's the workhorse, and going through `*WireGuardDialer` requires a
  live device. The Go convention is fine here: same-package test file
  can call the unexported function (use `package wireguard`, not
  `wireguard_test`, for `health_test.go`).
- **Acceptance Criteria:**
  - [ ] `*WireGuardDialer` satisfies `tunnel.HealthReporter` (compile-time
        assertion present in `dialer.go`).
  - [ ] `LastHandshake()` on a freshly constructed device returns
        `(time.Time{}, nil)`. (Handshake never completes — dead peer in
        `minimalOpts`.)
  - [ ] `parseLastHandshake` returns zero time + nil error on empty
        input.
  - [ ] `parseLastHandshake` returns zero time + nil error when every
        `last_handshake_time_sec` line is `0`.
  - [ ] `parseLastHandshake` returns `time.Unix(N, 0)` for a single peer
        with `last_handshake_time_sec=N` where N > 0.
  - [ ] `parseLastHandshake` returns the **maximum** across two peer
        blocks (defense against future multi-peer, even though we reject
        it in wgconf today).
  - [ ] `parseLastHandshake` skips lines it doesn't recognize
        (`private_key=...`, `public_key=...`, `endpoint=...`,
        `last_handshake_time_nsec=...`).
  - [ ] `parseLastHandshake` returns a non-nil error when a recognized
        line has a non-integer value (`last_handshake_time_sec=foo`).
  - [ ] One top-level `TestWireGuardDialer_LastHandshake` and one
        top-level `TestParseLastHandshake`. All scenarios as subtests.
  - [ ] `-race` clean.
- **Pitfalls:**
  - `IpcGet` writes to an `io.Writer` and returns `error`. Don't conflate
    its error with the "no handshake yet" case — the latter is a normal
    state, the former is a device failure.
  - `strings.HasPrefix` is fine but be careful with the trailing newline:
    `bufio.Scanner` strips it from `Text()`, so `line[len(prefix):]`
    doesn't need a `TrimRight`.
  - Don't import `bytes` just for `bytes.Buffer` — `strings.Builder`
    satisfies `io.Writer` and is the idiom already used in
    `buildIpcSet`.
  - Don't try to use `last_handshake_time_nsec`. We don't need
    sub-second resolution. Reading it adds parse paths for zero gain.
  - **Don't** log the UAPI Get output. It contains the private key
    (`private_key=<hex>`) and any preshared key (`preshared_key=<hex>`).
    The buffer goes from `IpcGet` to `parseLastHandshake` and is dropped.
    Never `opLog.Debug("uapi", "body", uapi)`. Never. Reviewers should
    grep for this.
  - `bufio.Scanner` default 64KB buffer is fine for one peer; even a
    pathological multi-peer mesh stays well under that.
- **Complexity:** Medium (the parser is small but the "never log this
  buffer" constraint is load-bearing).

### Task 3: New package `internal/health/` — handler + tests

- **Description:** Create `internal/health/health.go`:

  ```go
  // Package health implements the HTTP handler for the proxy's /healthz
  // liveness probe. The handler queries a tunnel.HealthReporter for the
  // last WireGuard handshake time and answers 200/503 with a fixed JSON
  // body shape. It is the sole consumer of HealthReporter today.
  package health

  import (
      "encoding/json"
      "log/slog"
      "net/http"
      "time"

      "httpproxy/internal/tunnel"
  )

  // NewHandler returns an http.Handler that responds to GET /healthz.
  //
  // The handler asks reporter.LastHandshake() for the time of the most
  // recent tunnel handshake and compares it against now. When
  // (now - handshake) <= maxAge the handler returns 200 with body:
  //     {"status":"ok","handshake_age_seconds":N}
  // Otherwise it returns 503 with body:
  //     {"status":"unhealthy","reason":<tag>,"handshake_age_seconds":N}
  // where <tag> is one of: "no_handshake" (handshake time is zero),
  // "handshake_stale" (age exceeds maxAge), or "reporter_error" (the
  // reporter returned a non-nil error). On "no_handshake" and
  // "reporter_error" the handshake_age_seconds field is -1 (sentinel —
  // no meaningful age).
  //
  // The handler logs at Debug for ok responses and Warn for 503
  // responses. opLog may be nil; if nil, slog.Default() is used.
  func NewHandler(reporter tunnel.HealthReporter, maxAge time.Duration, opLog *slog.Logger) http.Handler {
      logger := opLog
      if logger == nil {
          logger = slog.Default()
      }
      return &handler{reporter: reporter, maxAge: maxAge, now: time.Now, log: logger}
  }

  type handler struct {
      reporter tunnel.HealthReporter
      maxAge   time.Duration
      now      func() time.Time
      log      *slog.Logger
  }

  func (h *handler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
      if r.Method != http.MethodGet {
          http.Error(w, "", http.StatusMethodNotAllowed)
          return
      }
      ts, err := h.reporter.LastHandshake()
      if err != nil {
          h.write(w, http.StatusServiceUnavailable, response{
              Status:              "unhealthy",
              Reason:              "reporter_error",
              HandshakeAgeSeconds: -1,
          })
          h.log.Warn("healthz reporter error", slog.String("err", err.Error()))
          return
      }
      if ts.IsZero() {
          h.write(w, http.StatusServiceUnavailable, response{
              Status:              "unhealthy",
              Reason:              "no_handshake",
              HandshakeAgeSeconds: -1,
          })
          h.log.Warn("healthz no handshake yet")
          return
      }
      age := h.now().Sub(ts)
      ageSec := int64(age / time.Second)
      if age > h.maxAge {
          h.write(w, http.StatusServiceUnavailable, response{
              Status:              "unhealthy",
              Reason:              "handshake_stale",
              HandshakeAgeSeconds: ageSec,
          })
          h.log.Warn("healthz handshake stale", slog.Int64("age_seconds", ageSec))
          return
      }
      h.write(w, http.StatusOK, response{
          Status:              "ok",
          HandshakeAgeSeconds: ageSec,
      })
      h.log.Debug("healthz ok", slog.Int64("age_seconds", ageSec))
  }

  type response struct {
      Status              string `json:"status"`
      Reason              string `json:"reason,omitempty"`
      HandshakeAgeSeconds int64  `json:"handshake_age_seconds"`
  }

  func (h *handler) write(w http.ResponseWriter, status int, body response) {
      w.Header().Set("Content-Type", "application/json")
      w.WriteHeader(status)
      _ = json.NewEncoder(w).Encode(body) // unrecoverable; client gone
  }
  ```

  Tests in `internal/health/health_test.go`. **Required**: a fake
  reporter in the test file with a compile-time assertion. Tests
  inject `now` via a small package-internal test helper that
  constructs a `*handler` directly (the file uses `package health`,
  not `health_test`, so it can build the unexported struct). Pattern:

  ```go
  package health

  type fakeReporter struct {
      ts  time.Time
      err error
  }
  var _ tunnel.HealthReporter = (*fakeReporter)(nil)
  func (f *fakeReporter) LastHandshake() (time.Time, error) { return f.ts, f.err }

  func newTestHandler(reporter tunnel.HealthReporter, maxAge time.Duration, now time.Time) *handler {
      return &handler{
          reporter: reporter,
          maxAge:   maxAge,
          now:      func() time.Time { return now },
          log:      slog.New(slog.NewTextHandler(io.Discard, nil)),
      }
  }
  ```

  One top-level `TestNewHandler` covering all scenarios. Each scenario
  uses `httptest.NewRecorder` and decodes the body via
  `json.Unmarshal` into a `map[string]any` so field-leak regressions
  (a future contributor adds `"peer_endpoint":...`) fail the test via
  `len(map) == 2 or 3` assertions.

- **Acceptance Criteria:**
  - [ ] Package compiles; `go vet ./internal/health/...` clean.
  - [ ] `GET /healthz` with a reporter returning a fixed time 30s
        before the handler's injected `now`, and `maxAge = 180s` → 200,
        body decoded to map has exactly `{status: "ok",
        handshake_age_seconds: 30}` (exact field count, exact values).
  - [ ] `GET /healthz` with reporter returning zero time → 503,
        decoded body has `status=unhealthy`, `reason=no_handshake`,
        `handshake_age_seconds=-1`, exactly three fields.
  - [ ] `GET /healthz` with reporter returning a stale time (older
        than maxAge) → 503, `status=unhealthy`,
        `reason=handshake_stale`, `handshake_age_seconds=<actual age>`.
  - [ ] `GET /healthz` with reporter returning a non-nil error → 503,
        `status=unhealthy`, `reason=reporter_error`,
        `handshake_age_seconds=-1`.
  - [ ] `POST /healthz` → 405 (Method Not Allowed). Body contents
        unspecified; status is the assertion.
  - [ ] Response `Content-Type` header is `application/json` on all
        2xx and 5xx responses.
  - [ ] One top-level `TestNewHandler`. Every scenario above is a
        `t.Run`.
  - [ ] `fakeReporter` has a compile-time interface assertion at the
        top of the test file.
  - [ ] `-race` clean.
- **Pitfalls:**
  - `json.NewEncoder(w).Encode(body)` writes a trailing newline. Tests
    comparing exact JSON strings must account for it. Use
    `json.Unmarshal` into a map (recommended) — robust to whitespace.
  - **Don't** include `peer_endpoint`, `source`, or anything beyond the
    documented schema. Tests should assert the response body has
    **only** the documented fields. (Use `json.Unmarshal` into a
    `map[string]any` and check `len(map)` to catch accidental field
    leakage.)
  - The "now" injection matters more than it looks: if the test uses
    `time.Now()` to construct the stale timestamp and the handler also
    calls `time.Now()`, you have a ~1ms-to-seconds delta. Inject and
    fix it via `newTestHandler`.
  - Don't compute `handshake_age_seconds` as `int(age.Seconds())`. Use
    `int64(age / time.Second)` to floor — integer truncation matches
    operator expectations ("how many full seconds ago").
  - `503` is the correct status. Not 500, not 404. Document this for
    any future refactor.
  - `omitempty` on `Reason` matters: the 200 body has no `reason`
    field. Tests must NOT expect a `reason` key on success.
- **Complexity:** Medium.

### Task 4: New package `internal/transport/adminserver/`

- **Description:** Mirror `internal/transport/httpserver/server.go` but
  thinner — no hijack, no CONNECT, no proxyHandler test seam. The
  admin server is just an `*http.Server` with a `*http.ServeMux` and a
  graceful Shutdown.

  Create `internal/transport/adminserver/server.go`:

  ```go
  // Package adminserver wraps a small *http.Server bound to the proxy's
  // admin address (default 127.0.0.1:8081). It serves the liveness
  // probe at /healthz and nothing else; unknown routes return 404 via
  // http.ServeMux's default behaviour.
  //
  // The admin listener is intentionally separate from the proxy
  // listener: the proxy listener serves untrusted forward-proxy traffic
  // (and uses hijack for CONNECT), while the admin listener serves
  // operator/probe traffic with no hijack and a small surface. Running
  // them on the same *http.Server would force a shared middleware story
  // for two divergent use cases.
  package adminserver

  import (
      "context"
      "errors"
      "log/slog"
      "net"
      "net/http"
      "time"
  )

  // New constructs an admin server bound to opts.Addr that serves
  // opts.HealthHandler at /healthz. opLog may be nil; if nil
  // slog.Default() is used. opts.HealthHandler is required; New panics
  // if nil (implementation bug, not a config error).
  func New(opts Options, opLog *slog.Logger) *Server {
      logger := opLog
      if logger == nil {
          logger = slog.Default()
      }
      if opts.HealthHandler == nil {
          panic("adminserver: New requires a non-nil HealthHandler")
      }

      mux := http.NewServeMux()
      mux.Handle("/healthz", opts.HealthHandler)

      errLogger := slog.NewLogLogger(logger.Handler(), slog.LevelWarn)

      httpSrv := &http.Server{
          Addr:              opts.Addr,
          Handler:           mux,
          ReadHeaderTimeout: 5 * time.Second,
          IdleTimeout:       30 * time.Second,
          // WriteTimeout is fine here (no hijack, no streaming).
          WriteTimeout: 5 * time.Second,
          ErrorLog:     errLogger,
      }
      return &Server{http: httpSrv, log: logger}
  }

  // Options configures the admin server.
  type Options struct {
      // Addr is the bind address, "host:port" form. Required (config
      // applies the 127.0.0.1:8081 default before construction).
      Addr string
      // ShutdownTimeout is held by the caller, not the Server; New
      // ignores it. Present in Options for forward-compat and to make
      // the call site self-documenting at the caller.
      ShutdownTimeout time.Duration
      // HealthHandler serves GET /healthz. Required; New panics if nil.
      HealthHandler http.Handler
  }

  // Server wraps *http.Server and exposes Start/StartOn/Shutdown.
  type Server struct {
      http *http.Server
      log  *slog.Logger
  }

  // Start begins listening and serving. Returns nil on graceful
  // Shutdown, the actual error otherwise.
  func (s *Server) Start() error {
      s.log.Info("admin server listening", slog.String("addr", s.http.Addr))
      if err := s.http.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
          return err
      }
      return nil
  }

  // StartOn serves on an already-bound listener. Same return semantics
  // as Start. Intended for tests that bind the listener before passing
  // the address downstream (avoids the TOCTOU race of "grab a free
  // port then listen").
  func (s *Server) StartOn(ln net.Listener) error {
      s.log.Info("admin server listening", slog.String("addr", ln.Addr().String()))
      if err := s.http.Serve(ln); err != nil && !errors.Is(err, http.ErrServerClosed) {
          return err
      }
      return nil
  }

  // Shutdown gracefully stops the server. The caller's ctx bounds the
  // wait; if it's already done, Shutdown returns immediately.
  func (s *Server) Shutdown(ctx context.Context) error {
      return s.http.Shutdown(ctx)
  }
  ```

     Note: `wgDialer` is `*WireGuardDialer`, which implements
     `tunnel.HealthReporter` (verified at compile time in Task 2). The
     call site does NOT need a type assertion — the concrete type
     satisfies the interface implicitly. If the engineer ever changes
     `NewDialer` to return `tunnel.Dialer`, add the assertion at that
     moment.

  2. Replace the existing single-goroutine error channel pattern with
     a buffered channel of size 2 collecting from both servers:

     ```go
     errCh := make(chan error, 2)
     go func() { errCh <- srv.Start() }()
     go func() { errCh <- adminSrv.Start() }()

     select {
     case err := <-errCh:
         // one side failed to start; treat as fatal startup failure.
         // the other goroutine's send is non-blocking (buffer size 2)
         // so we don't leak it even though we never read its value.
         return fmt.Errorf("server start: %w", err)
     case <-ctx.Done():
         opLog.Info("shutdown signal received")
     }
     ```

  3. Replace the single-shutdown block with sequential shutdowns,
     proxy first (it's the long-lived one with CONNECT tunnels that
     need time to drain), admin second (cheap):

     ```go
     shutdownCtx, cancel := context.WithTimeout(context.Background(), cfg.ShutdownTimeout)
     defer cancel()

     var shutdownErr error
     if err := srv.Shutdown(shutdownCtx); err != nil {
         opLog.Error("proxy shutdown failed", "err", err.Error())
         shutdownErr = fmt.Errorf("proxy shutdown: %w", err)
     }

     adminShutdownCtx, adminCancel := context.WithTimeout(
         context.Background(), cfg.Admin.ShutdownTimeout)
     defer adminCancel()
     if err := adminSrv.Shutdown(adminShutdownCtx); err != nil {
         opLog.Error("admin shutdown failed", "err", err.Error())
         if shutdownErr == nil {
             shutdownErr = fmt.Errorf("admin shutdown: %w", err)
         }
     }

     if shutdownErr != nil {
         return shutdownErr
     }
     opLog.Info("shutdown complete")
     return nil
     ```

     **Defer order is critical.** The existing `defer wgDialer.Close()`
     runs LAST (LIFO), AFTER both server shutdowns return — that's
     what we want. New `adminSrv` does not have its own
     `defer Close()`; its lifecycle ends inside the explicit
     `adminSrv.Shutdown` call above.

  4. Add the new imports at the top of main.go:
     ```go
     "httpproxy/internal/health"
     "httpproxy/internal/transport/adminserver"
     ```

  5. The startup log line for the admin server is emitted inside
     `adminSrv.Start` (per Task 4) — no extra log call in main.go.
     The existing `"upstream wireguard ready"` log stays unchanged;
     it does not mention the admin port.

## Execution Order

Strict sequential: **1 → 2 → 3 → 4 → 5 → 6 → 7 → 8**.

Rationale:
- **Task 1** (HealthReporter interface) is a leaf with no callers; it
  lands first so Task 2 has something to implement against.
- **Task 2** (WG `LastHandshake` impl) consumes Task 1.
- **Task 3** (health handler) consumes Task 1 (the interface) but
  does NOT consume Task 2 directly — it uses `tunnel.HealthReporter`
  and a fake reporter in tests. The handler is independently testable
  before the WG implementation is wired into main.
- **Task 4** (`adminserver`) consumes nothing from 1–3; it's a thin
  `*http.Server` wrapper. Could theoretically run in parallel with
  Tasks 1–3.
- **Task 5** (config schema) consumes nothing from 1–4. Could run in
  parallel.
- **Task 6** (wiring) consumes everything 1–5.
- **Tasks 7, 8** (smoke + docs) cannot start until 6 is green.

**Parallelizable subset**: Tasks 4 and 5 are independent of each
other and of Tasks 1–3. A multi-engineer team could fan out 1+2+3,
4, and 5 concurrently. For a single engineer, sequential is simpler
and the ordering above minimizes context switches. **Tasks 3 and 4
must finish before 6**.

## Risks

- **(a) `IpcGet` output format drift between wireguard-go versions.**
  The `last_handshake_time_sec=<int>` line is part of the UAPI
  protocol spec at wireguard.com/xplatform; it's a published wire
  format and unlikely to change incompatibly. But pinning is still
  cheap: `go.mod` pins `golang.zx2c4.com/wireguard` to a specific
  revision (verify current pin in `go.mod`); the parser is defensive
  (skips unknown keys), so adding new lines won't break us.
  **Mitigation**: don't fail-closed on unknown lines; we already
  don't.
- **(b) `handshake_max_age` too low → flapping; too high → masks
  real outages.** Default 180s = 3× the 25s persistent keepalive
  plus 105s buffer. Operator can tune. Documented in the config
  godoc and the README. **Mitigation**: ship a sensible default,
  document why it is what it is.
- **(c) Race between `LastHandshake()` and `Close()`.** If
  `/healthz` is being polled at the moment SIGINT fires and
  `Close()` runs, `IpcGet` on a closing device may return an error.
  The handler maps it to `reason=reporter_error` (503), which is
  correct: the proxy is shutting down, so reporting unhealthy is
  accurate. **Mitigation**: the contract already covers this —
  `LastHandshake` returning an error is documented; the handler
  handles it.
- **(d) Admin listener port collision.** If 8081 is already bound by
  something else, the admin server fails to start and `run()`
  returns the error. The proxy server may already be listening at
  that point (goroutines start in parallel). **Acceptable for v4**:
  the operator sees the error message, picks a different port. The
  proxy server's Shutdown is called as the defer/select machinery
  unwinds — no leak.
- **(e) "Tunnel-status oracle" attack on `0.0.0.0:8081`.** If an
  operator changes the bind to `0.0.0.0`, anyone on the network can
  poll `/healthz` and infer "tunnel is up" or "tunnel just rotated."
  This is an operator-opt-in security tradeoff; documented in README
  and CLAUDE.md. **Not mitigated in code** — adding token auth is a
  separate plan if/when wanted.
- **(f) `time.Now()` clock skew during age computation.** The
  handler's `now()` and the WG device's clock are the same process'
  `time.Now()`, so no skew. If wireguard-go ever switches to a
  monotonic-ticking source for `last_handshake_time_sec`, our
  `time.Unix()` conversion silently breaks. **Mitigation**: parser
  is centralized; a future fix is one file.
- **(g) Test flake on age boundaries.** A subtest that constructs a
  reporter at "exactly maxAge ago" can race the clock and flip
  between 200 and 503. **Mitigation**: tests use injected `now`
  (see Task 3); no real-clock arithmetic except integration smoke.
- **(h) Double-listening port log noise.** `make run` now prints
  two `listening` log lines; operators may interpret as a duplicate.
  The admin line uses `"admin server listening"` to disambiguate.
  Documented in Task 6 pitfalls; engineer must NOT collapse them
  into one line.
- **(i) Lost startup error from second goroutine.** When both
  servers fail to start, the select only reads one error; the other
  is buffered in `errCh` and dropped. Acceptable: the first error is
  enough to diagnose; both failing is rare; the alternative
  (draining errCh on shutdown) adds shutdown complexity for marginal
  observability. **Mitigation**: both Start() calls log their own
  errors via `http.Server.ErrorLog`; the dropped one is still on
  stderr.

## Trade-offs

- **(a) Probe strategy: handshake-age vs handshake-age+active-dial
  vs config-toggled.** Chose handshake-age-only. Why: wireguard-go
  updates `last_handshake_time_sec` only on real handshake completion
  (initiation OR keepalive-triggered rekey), so a fresh handshake
  age strongly implies a working tunnel. Active dialing to
  `1.1.1.1:443` would add ~100ms+ latency per probe, an extra
  failure surface (DNS, TCP, TLS), one more thing to mock in tests,
  and a "what if Cloudflare is down but Mullvad is fine" false-
  positive. **If we ever discover that handshake age stays fresh
  while traffic silently fails, we add the active dial then** —
  likely as a config-toggled option, not a default.
- **(b) `HealthReporter` as a standalone optional interface vs
  sub-interface of `Dialer`.** Chose standalone (not embedding
  `Dialer`). Why: the /healthz handler depends on `LastHandshake`
  only; coupling health to dialing would force every fake reporter
  in tests to satisfy `Dialer` too (a `DialContext` method that does
  nothing). Standalone keeps the test surface tight. `DialerCloser`
  embeds `Dialer` because a closer IS a dialer (lifecycle of the
  same object); a reporter is not.
- **(c) `adminserver` as its own package vs second mux in
  `httpserver/`.** Chose own package. Why: proxy and admin have
  divergent timeouts (proxy WriteTimeout=0 for CONNECT, admin
  WriteTimeout=5s), divergent handler shapes (hijack vs ServeMux),
  divergent bind addresses (`Listen` vs `Admin.Listen`), and
  divergent middleware needs (proxy has access logging, admin has
  Debug log per request). Sharing the package would require a
  generic `serverFactory(opts)` abstraction that adds complexity for
  two callers. **Single consumer** (`cmd/httpproxy`) still earns its
  `internal/` placement because the abstraction is reusable in
  principle if a second binary ever needs an admin port.
- **(d) `health.NewHandler` in `internal/health/` vs
  `cmd/httpproxy/`.** Chose `internal/health/`. The strict
  consumption rule says single-consumer code lives in `cmd/`. The
  test ergonomics argument wins here: a separate package lets the
  test file use idiomatic table tests with fakes, without dragging
  `main` into the test compile graph. **One file, one test file,
  one consumer** — borderline but justified. If a future second
  consumer never materializes and the test ergonomics argument
  weakens, this is a low-cost move back to `cmd/httpproxy/`.
- **(e) 503 body schema: minimal vs include
  `handshake_age_seconds`.** Chose include. Why: the operator's
  first question on a 503 is "how stale?" — putting the number in
  the body avoids "now correlate the 503 timestamp with the log
  line." Minor cost: one extra field. The 3-field schema is small
  enough that schema drift risk is low.
- **(f) Sentinel `-1` for unknown age vs omit the field.** Chose
  `-1`. Why: stable schema is easier for operator scripts to parse;
  a missing field plus an `omitempty` tag is one more conditional in
  their JSON consumer. `-1` is unambiguous as "no age available"
  (real handshake ages are non-negative integers).
- **(g) No `/metrics` in v4.** Chose strict scope. Why: Prometheus
  exposure deserves its own plan (cardinality, labels, registry
  lifecycle, dependencies on `prometheus/client_golang` — adds ~5MB
  binary). v4 = liveness only.
- **(h) No `DisallowUnknownFields` flip.** Kept current
  permissive-decode behavior. Why: changing it as a side effect of
  this plan would silently break any operator's `proxy.json` that
  has a stale field (e.g. legacy `kind` from v2). If we want strict
  mode it's a separate plan with a deprecation cycle. Documented in
  Pitfalls of Task 5.
- **(i) Both servers share `cfg.ShutdownTimeout` budget or each get
  their own?** Chose separate. Proxy uses `cfg.ShutdownTimeout`
  (15s default for CONNECT tunnel drain); admin uses
  `cfg.Admin.ShutdownTimeout` (5s, no long-lived connections to
  drain). Sharing one 15s budget would mean a slow proxy drain
  delays the admin shutdown by up to 15s — no operational benefit.
- **(j) Goroutine count: two for servers (one per Start) vs one
  multi-server runloop.** Chose two. Why: each
  `http.Server.ListenAndServe` blocks; running them in one goroutine
  requires a select on multiple channels with shutdown coordination,
  more code than two goroutines + one buffered errCh. The buffered
  errCh size (2) handles the case where both fail to start before we
  get to the select.
- **(k) `Options.ShutdownTimeout` lives on the Options struct even
  though `adminserver.New` ignores it.** Caller owns the
  `context.WithTimeout` because Shutdown is called from the same
  signal-handling block as the proxy's. Keeping the field in
  `Options` makes the call site self-documenting ("here's the budget
  this server was meant to get") and leaves room for the server to
  enforce it internally in a future iteration if the caller pattern
  becomes painful. Small cost; document the "ignored at construction"
  contract in the field's godoc.
